Lantern Line is a gravity courier game: you are a paper lantern with a candle inside, crossing five sectors of ink and tide. Sling yourself from the post to the first gate, then from that ring to the next, and set down on the far post before the wax burns out. Drag back from the lantern to aim, release to fly, tap space for two ember puffs that nudge the drift, and press R to go back to the last ring you caught.

## Run it

```sh
node serve.ts && open http://localhost:8080
```
